# BlackoutRadar

> Архитектурная и техническая документация проекта BlackoutRadar.

---

# О проекте

BlackoutRadar — система мониторинга плановых отключений электроэнергии.

Основная задача проекта — автоматически получать информацию об отключениях из различных источников, сопоставлять ее с адресами пользователей и своевременно отправлять уведомления по выбранным каналам связи.
